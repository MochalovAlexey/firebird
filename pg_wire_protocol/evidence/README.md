# Исходное наблюдение за драйвером

[driver_probe.json](driver_probe.json) перенесён из приложенного пакета без изменений. В нём описан обмен psycopg2 2.9.11 / libpq 17.6 с синтетическим локальным сервером: Simple Query, BEGIN/COMMIT/ROLLBACK и адаптация значений.

В этом опыте SQL не выполнялся в Firebird. JSON не является результатом приёмки M0–M3. Скрипт синтетического сервера среди переданных файлов отсутствует; опыт здесь повторно не воспроизводился.

Текущие результаты настоящего endpoint впоследствии записываются в `../VALIDATION.md` с точными командами, версиями и идентификаторами проверок.
